# KeepSake 
Your personal web app to keep memories worth preserving safe and secure in your personal tab with journal and image.
## Status - complete v1

##  Demo
[**KeepSake Live**](https://udayprakash999.github.io/KeepSake/)

## Tech Stack
- HTML
- CSS
- JS
- Indexed DB
- Font Awesome

## How to use
- Click add memory and fill the form to add a memory with the moment you captured to keep it preserved, reset button is dangerous so press it on your own responsiblity. You can also click the small memory cards to read your own journal.

## Features
- Add memories worth keeping secured and safe in this app
- You can add images with it 
- Keep important moments preserved with notes and journals

## What I learnt
- I learned about how and why to use indexed DB and it was so much more useful than saving textual information to local storage
- I also learned to use clean and proper structure of a web/app using featur-based architecture.
