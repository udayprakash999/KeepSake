# KeepSake 
Your personal web app to keep memories worth preserving safe and secure in your personal tab with journal and image.
## Status - complete v1

##  Demo
[**KeepSake Live**](https://udayprakash999.github.io/KeepSake/)

## Tech Stack
- HTML
- CSS
- JS
- Indexed DB
- Font Awesome

## Features
- Add memories worth keeping secured and safe in this app
- You can add images with it 
- Keep important moments preserved with notes and journals
